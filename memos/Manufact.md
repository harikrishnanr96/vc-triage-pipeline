## Product

Manufact provides hosting, cross-client testing, publishing checks, a submission pack, a cloud inspector, and analytics for MCP servers and apps.

- "Manufact (formerly mcp-use) is a platform for deploying, testing, observing, and publishing MCP servers and MCP apps." ([website](https://manufact.com))

## Market

**Size:** The market is growing rapidly as major tech companies adopt MCP, with some reporting that over 15% of their usage already comes from their MCP servers.
- "All major tech companies have an MCP server, and many of those are reporting that already 15+% of their usage comes from their MCP" ([HN post](https://news.ycombinator.com/item?id=48762862))

**Competitors:** Skybridge, Stainless, Vercel. Competitors and alternatives mentioned include Skybridge (a TypeScript framework for MCP), Stainless (which users are migrating off of), and general hosting platforms like Vercel.
- "You may want to have a look at Skybridge, a TypeScript framework designed to build MCP servers and MCP Apps" ([HN comment by harijoe](https://news.ycombinator.com/item?id=48762862))
- "i'm migrating off stainless after anthropic bought them, we have to be off by september" ([HN comment by ICodeSometimes](https://news.ycombinator.com/item?id=48762862))

**Why now:** MCP is reaching a maturity milestone as major clients open marketplaces for one-click installation and dynamically present MCP servers based on user intent.
- "We feel that MCP is reaching its maturity moment. Now that MCPs are starting to be easy to install and discover" ([HN post](https://news.ycombinator.com/item?id=48762862))
- "Clients (Claude, ChatGPT, Cursor) are starting to dynamically present MCP servers/apps to users, based on their intent." ([HN post](https://news.ycombinator.com/item?id=48762862))

  - "MCP is a protocol, that's all." ([HN comment by saberience](https://news.ycombinator.com/item?id=48762862))

## What would change the call

- If major AI clients like Claude or ChatGPT deprecate or move away from the MCP standard.
- If general-purpose hosting platforms like Vercel introduce native, seamless MCP testing and deployment features that match Manufact's workflow.
- If the open-source mcp-use SDK downloads and GitHub stars stop growing, indicating a decline in developer interest.
